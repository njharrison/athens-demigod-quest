# Athens Demigod Quest

An offline-first, installable mythology quest for Matilda and Alana, guided by Emma and Nanny.

## Publish

GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Then open https://njharrison.github.io/athens-demigod-quest/ in Safari, Share → Add to Home Screen. Open once while online and test Airplane Mode.

Progress is stored independently in each browser/device. Export/import JSON backups are supported. External Google Maps links need connectivity.
